# Data Cleaning & Visualization Project

## 📌 Project Overview

This project demonstrates a complete **data preprocessing, cleaning, visualization, and data storytelling workflow** using Python.

A raw retail sales dataset is intentionally prepared with:
- Missing values
- Duplicate records
- Extreme/outlier values
- Different data types

The dataset is then cleaned with **Pandas** and analyzed through visualizations created with **Matplotlib**.

---

## 🎯 Objective

The main objective is to transform a raw dataset into a reliable analysis-ready dataset and communicate useful business insights through charts.

### Project workflow

**Raw Dataset → Data Understanding → Data Cleaning → Outlier Handling → Feature Engineering → Visualization → Insights**

## 📊 Dataset Description

The project uses a retail sales dataset containing order-level information.

### Main columns

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| Order_Date | Date of the order |
| Product | Product purchased |
| Category | Product category |
| Region | Sales region |
| Quantity | Number of units sold |
| Unit_Price | Price per unit |
| Discount | Discount applied |
| Revenue | Sales revenue |
| Cost | Estimated cost |
| Profit | Revenue minus cost |

The raw dataset contains intentionally introduced data-quality issues so that the cleaning process can be demonstrated.

# 🧹 Data Cleaning Process

## 1. Standardize column names

Column names are converted into lowercase and underscore-separated format.

Example:

```text
Order Date → order_date
Unit Price → unit_price
```

---

## 2. Handle missing values

Missing values are treated according to their data type.

### Categorical column

```python
df["region"] = df["region"].fillna("Unknown")
```

### Numeric columns

The median is used for missing numeric values.

```python
df["quantity"] = df["quantity"].fillna(df["quantity"].median())
```

Median is useful because it is less affected by extreme values than the mean.

---

## 3. Remove duplicates

Duplicate rows are identified and removed.

```python
df = df.drop_duplicates()
```

This prevents the same transaction from being counted multiple times.

---

## 4. Handle outliers

The project uses the **Interquartile Range (IQR)** method.

Formula:

```text
IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 × IQR

Upper Bound = Q3 + 1.5 × IQR
```

Extreme values in quantity and unit price are capped using these limits.

---

## 5. Feature engineering

Revenue and profit are recalculated after cleaning.

### Revenue

```text
Revenue = Quantity × Unit Price × (1 - Discount)
```

### Profit

```text
Profit = Revenue - Cost
```

### Profit Margin

```text
Profit Margin = Profit / Revenue
```
